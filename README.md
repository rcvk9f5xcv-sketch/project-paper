# Project Paper

Dieses Repository enthält Materialien und Analysen für ein Studienprojekt im Bereich Textanalyse mit R.

## Inhalt

- `corpus/`  
  Enthält die verwendeten Textdaten (Samples).

- `RScript/`  
  R-Skripte zur Durchführung der Analysen:
  - MFW-Analyse
  - Lexikalische Diversität
  - Sampling
  - Satzlängenanalyse

- `Tables_Figures/`  
  Ergebnisse der Analysen:
  - Tabellen
  - Grafiken (z. B. PCA)
  - Ausgabedateien
